# AI Intelligent Outfit Assistant
# AI智能穿搭助手
是一个基于C语言开发的命令行穿搭推荐工具，输入用户身高体重、性别、肤色、季节、天气、出行场合等信息，自动计算BMI体型，推荐适配色系，结合季节与场景生成全套穿搭方案，包含衣物、鞋履、配饰与妆容建议，同时提供体型穿搭提示、雨天特殊穿搭提醒。

## 环境配置
程序运行需要Windows操作系统，使用MinGW GCC编译时执行命令`gcc AI智能穿搭助手.cpp -o outfit.exe -std=c99`，使用Dev-C++可直接打开cpp源码编译运行。所有依赖均为C语言标准库（stdio.h、string.h、stdlib.h），无需额外安装第三方库。

## 运行步骤
编译生成可执行文件outfit.exe。双击运行或在命令行中执行`./outfit.exe`，按照控制台提示依次输入身高体重、性别、季节、天气、肤色、出行场合信息，程序自动计算并输出完整穿搭分析报告。

## 功能说明
1. 个人信息采集：交互式输入用户身高、体重、性别、肤色、季节、温湿度、是否下雨、出行场景等基础信息，构建用户个人资料结构体。
2. BMI体型判定：根据身高体重自动计算BMI，判断体型（偏瘦/标准/微胖/偏胖），给出对应体型穿搭优化建议。
3. 肤色色彩推荐：根据用户肤色类型，推荐适合的穿搭色系与需要避开的颜色，提升穿搭视觉效果。
4. 分场景智能穿搭推荐：根据季节（春夏秋冬）+天气+性别+场合（职场通勤、约会、休闲、运动、正式场合），生成完整穿搭方案，包含上衣、下装、鞋子、配饰、妆容/造型。
5. 特殊天气提示：如果检测到下雨，额外给出雨天穿搭提醒，推荐雨具、防水鞋包与避坑建议。
6. 穿搭总结输出：整合所有信息打印完整个人穿搭分析报告，最后给出穿搭温馨提示。
